# 《末法寻仙》总稿说明

本目录提供两份便于全文检索、通读和投喂 AI 的合并稿。原分文件仍是维护源，总稿是生成结果，不直接修改。

## 设定总稿

`设定总稿.md` 按顺序合并 `设定/整合设定/00` 至 `16`，共 17 份现行权威文档。

以下内容不并入现行设定总稿：

- `设定/第一版` 至 `第七版`：历史版本，冲突时不得覆盖整合设定；

## 写作流程总稿

`写作流程总稿.md` 合并当前实际使用的 6 份文件：日常入口、最高律令、最新状态卡、高频规则、单章工作卡和章节概况模板。

旧版 `ai写作流程.txt` 仅作复杂章节和纠错指令参考，不并入日常总稿。

## 更新方式

设定、状态卡或流程文件发生变化后运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\生成总稿.ps1"
```

生成结果会覆盖两份总稿，但不会修改任何源文件。
