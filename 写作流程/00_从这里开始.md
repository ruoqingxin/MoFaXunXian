# 《末法寻仙》日常写作工作台

这份文件是每次开写时唯一需要先打开的入口。

## 一、规则优先级

发生冲突时，按以下顺序裁定：

1. `1.最高律令.txt`：不可违反的叙事红线。
2. `2.当前状态追踪卡.txt`：上一章已经落地的事实。
3. `设定/整合设定/14_术语与冲突裁定.md`：术语和版本冲突。
4. 与本章直接相关的整合设定文件。
5. `设定/整合设定/12_写作规范.md`：结构、节奏和表达标准。
6. 旧版设定：仅用于补充，不得覆盖整合设定。

不再每次投喂全部设定。每章只加载“最高律令 + 当前状态 + 本章相关设定”，通常控制在 3 至 5 份文件。

## 二、四步闭环

### 1. 填章卡

复制 `4.单章工作卡.md`，用不超过 10 行回答章卡问题。第 2、3、8、9 项任何一项答不出来，就先改剧情，不写正文。

本步只确定：主动目标、阻碍、转折、选择与代价、章末状态变化。不要提前润色句子。

### 2. 一次成稿

常规章按章卡一次生成或写完 2800 至 3800 字的干净草稿，直接保存到 `准备章节`。写作时在脑内按场景分块，但不再默认执行“逐场景扩写—人工审核—重新组装”。那套流程只用于以下情况：

- 重点战斗、多人博弈或复杂撤离；
- 同时涉及 3 个以上地点或视角；
- 初稿连续两次出现因果错误。

正文中不得保留 `【AI标注】`、提示词、自检报告或作者解释。疑点统一记在工作卡的“待裁定”栏。

### 3. 两轮检查

先结构，后语言，不交叉返工。

**结构轮（必须全过）**

- 主角是否主动改变了局势；
- 结尾相较开头是否至少改变 2 项状态；
- 视角、身份权限、时间、伤势与资源能否连续；
- 魂印、坐标、遗藏、遗蜕等对象是否分清；
- 章末是否完成局部兑现，而不是只增加谜团。

任一项失败，退回章卡或场景层重写，不做逐句润色。

**语言轮（结构通过后再做）**

- 删除重复感知、同义心理总结和无效说明；
- 检查对话声音、空间关系、标点和计量；
- 运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\检查章节.ps1" -Path ".\准备章节\第一至第十章\第二章_章名.md"
```

脚本只抓机械问题，不能代替人工判断因果和人物选择。

### 4. 定稿即同步

人工通读通过后，在同一次工作中完成以下动作，缺一项都不算定稿：

1. 将正文复制到 `正式章节` 对应目录；
2. 按 `5.章节概况模板.md` 新建该章概况，保存到 `章节概况` 的对应分组目录；
3. 从章节概况的“章后”列同步更新 `2.当前状态追踪卡.txt`；
4. 新人物、具名遗蜕、关键伏笔分别登记到对应总表；
5. 完成章节概况末尾的“定稿同步确认”。
6. 运行 `写作流程/工具/生成总稿.ps1`，把最新状态卡同步进 `总稿/写作流程总稿.md`。

正式正文、章节概况和当前状态卡必须指向同一个章后状态。任一项没更新，下一章不得开写。

最后对正式正文运行定稿检查，强制确认对应概况存在：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\检查章节.ps1" -Path ".\正式章节\第一至第十章\第二章_章名.md" -RequireOverview
```

同步总稿：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\生成总稿.ps1"
```

三者职责不同：

- `正式章节`：读者最终看到的正文，是事实来源；
- `章节概况`：每章永久保留的变化快照，用于追溯；
- `当前状态追踪卡`：只保留最新状态，供下一章冷启动。

## 三、给 AI 的最短指令

每次只需要发送下面这段，并附章卡与相关文件：

```text
按《最高律令》和当前状态执行本章工作卡。先检查章卡第2、3、8、9项是否成立；若有硬冲突，只列冲突并停止。若无冲突，直接输出干净正文，不附AI标注、自检报告或创作说明。不得补写设定中未定稿的事实，疑点留在正文外的“待裁定”列表。
```

修改已有章节时，明确限定修改层级：

- `结构修改`：允许改事件顺序、场景和结果；
- `局部重写`：只改指定段落，保持前后事实；
- `语言精修`：不得新增事件、设定、资源或人物动机。

## 四、每 5 章一次维护

不要每章都整理全套设定。每完成 5 章，再集中检查一次：

- 时间线、资源账、伤势和装备是否累计一致；
- 章节概况是否连续，上一章“章后”能否接上下一章“章前”；
- 近 3 章是否完成至少一次承诺兑现；
- 新术语、人物、伏笔与遗蜕是否漏登；
- 同类开头、爽点和章末悬念是否重复；
- 状态卡中已经失效的问题是否清除。
