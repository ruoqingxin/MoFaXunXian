# 写作工具使用说明

本目录包含两个 PowerShell 工具：

- `检查章节.ps1`：检查章节中的机械问题，不修改正文。
- `生成总稿.ps1`：根据源文件重新生成设定总稿和写作流程总稿。

文件路径包含中文时必须使用引号。运行命令前先看 PowerShell 提示符中的当前目录，不要重复拼接路径。

如果提示符是项目根目录：

```text
PS E:\创作\MoFaXunXian>
```

使用本文各节给出的完整相对路径，例如：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\生成总稿.ps1"
```

如果提示符已经是工具目录：

```text
PS E:\创作\MoFaXunXian\写作流程\工具>
```

直接使用当前目录下的脚本名：

```powershell
powershell -ExecutionPolicy Bypass -File ".\生成总稿.ps1"
```

此时不要再写 `.\写作流程\工具\`，否则系统会到工具目录下面继续寻找一层不存在的 `写作流程\工具`。

## 一、检查准备章节

草稿写完后运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\检查章节.ps1" `
  -Path ".\准备章节\第一至第十章\第二章_章名.md"
```

工具会检查：

- 正文长度是否在目标范围内；
- 是否残留 `【AI标注】`、交稿自检报告等AI痕迹；
- 对话是否误用英文引号；
- 省略号是否误用为 `...` 或单个 `…`；
- “他意识到、他明白、他知道”是否使用过多；
- 是否使用旧境界名“行气”；
- 是否存在行尾空格。

草稿模式不要求章节概况，因此 `Chapter overview` 显示 `SKIP` 属于正常结果。

## 二、自定义字数范围

默认范围是2400至6000个非空正文字符。重点章可以自行指定：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\检查章节.ps1" `
  -Path ".\准备章节\第一至第十章\第二章_章名.md" `
  -MinLength 2800 `
  -MaxLength 4800
```

这里是本地近似统计，最终字数以发布平台显示为准。

## 三、检查正式章节

定稿前，正式正文与章节概况必须使用对应名称：

```text
正式章节/第一至第十章/第二章_章名.md
章节概况/第一至第十章/第二章_章名_概况.md
```

完成正文、章节概况和状态卡同步后运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\检查章节.ps1" `
  -Path ".\正式章节\第一至第十章\第二章_章名.md" `
  -RequireOverview
```

`-RequireOverview` 会根据正式正文的分组目录和文件名自动寻找对应概况。缺少概况或名称不一致时，`Chapter overview` 显示 `REVIEW`。

## 四、理解检查结果

| 结果 | 含义 | 应对方式 |
| --- | --- | --- |
| `PASS` | 该项机械检查通过 | 继续下一项检查 |
| `REVIEW` | 发现需要人工确认的问题 | 根据 `Detail` 定位并修正 |
| `SKIP` | 当前模式不执行该项 | 草稿模式下属于正常结果 |

只要存在一个 `REVIEW`，脚本就会返回退出码 `1`。全部通过时返回退出码 `0`。

这个工具不能判断以下问题，仍需按《12_写作规范.md》人工检查：

- 人物动机和主角主动性；
- 视角信息是否合理；
- 身份、权限与专业能力；
- 灵力、伤势、装备和时间的剧情连续性；
- 战斗胜负、资源收益和章末兑现是否成立。

## 五、重新生成总稿

修改以下任一内容后，应重新生成总稿：

- `设定/整合设定/00`至`16`；
- 日常写作流程、最高律令或快捷规则；
- 当前状态追踪卡；
- 单章工作卡或章节概况模板。

运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\写作流程\工具\生成总稿.ps1"
```

如果当前已经位于 `写作流程\工具`，则运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\生成总稿.ps1"
```

生成结果：

- `总稿/设定总稿.md`
- `总稿/写作流程总稿.md`

总稿是自动生成文件，会被覆盖。需要修改内容时应编辑原始分文件，再重新运行工具；不要直接编辑总稿。

## 六、推荐定稿顺序

1. 在 `准备章节` 完成草稿。
2. 运行草稿检查。
3. 按结构硬检和语言检查修正正文。
4. 将正文放入 `正式章节`。
5. 新建同名章节概况，记录章前章后变化。
6. 用章节概况的章后状态更新当前状态追踪卡。
7. 登记新增人物、具名遗蜕、伏笔和设定变动。
8. 使用 `-RequireOverview` 运行正式章节检查。
9. 运行 `生成总稿.ps1`。
